# JNTUH E-Cell Chatbot

A grounded FAQ chatbot developed as a mini project to help students access information about entrepreneurship, startups, incubation, innovation, funding, and opportunities within the JNTUH startup ecosystem.

## Features
- FAQ-based grounded responses
- Startup and entrepreneurship knowledge base
- JNTUH E-Cell focused information
- Retrieval-based chatbot design

## Technologies Used
- Python
- Streamlit
- Sentence Transformers
- Scikit-learn
- Pandas
